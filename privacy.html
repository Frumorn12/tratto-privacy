Informativa sulla privacy di Tratto

Ultimo aggiornamento: 27 settembre 2026.

Quali dati usa Tratto

Tratto salva sul dispositivo le note scritte dall'utente (tratti di penna, pagine, PDF importati, cartelle). Tratto non ha server propri, non contiene pubblicità né strumenti di analisi e non invia le note a terzi.

Backup su Google Drive

Solo se l'utente collega il proprio account Google, Tratto carica una copia delle note nel suo Google Drive, in una cartella chiamata «Tratto». Tratto usa il permesso drive.file: può leggere e modificare soltanto i file che crea lui, e non vede gli altri file del Drive. I dati ricevuti dalle API di Google sono usati solo per il backup e il ripristino delle note dell'utente, nel rispetto delle Norme relative ai dati utente dei servizi API di Google, compresi i requisiti di Uso limitato.

Riconoscimento della scrittura

La trascrizione della scrittura usa il riconoscimento di Google ML Kit, che funziona sul dispositivo: la prima volta scarica il modello della lingua, poi il riconoscimento avviene senza inviare le note.

Cancellazione

L'utente può eliminare le note dall'app, cancellare la cartella «Tratto» dal proprio Drive e scollegare l'account dalle impostazioni di Tratto o da myaccount.google.com/permissions.
